# ISMRM2027_31P_Quantification

Code for the ISMRM 2027 abstract:

> **How robust is 7T ³¹P-MRS quantification? Comparison of four fitting algorithms applied to quantify PCr/γ-ATP and NAD⁺/NADH**
> J. Karkouri, U. H. Chan, O. Ipek, A. Naegel, S. McElroy, T. R. Eykyn, V. McLin, B. Lanz, A. Egerton, C. T. Rodgers, C. Cudalbu

The same 7T ³¹P brain spectra (simulated with known truth, and in vivo from 3D UTE-CSI) are quantified with four algorithms. All four use one common basis, so that the differences come from the algorithm rather than from the prior knowledge:

| Algorithm | Implementation in this repository |
|---|---|
| In-house | `fit_31P_spectrum_v4_cs.m`: frequency-domain VARPRO fit with a spline baseline |
| LCModel | `lcm_benchmark.m` (simulations) and `fit_real_3way.m` (in vivo) |
| AMARES (OXSA) | `make_amares_pk.m` turns the basis into prior knowledge, and `amares_fit_spectrum.m` runs the fit |
| FSL-MRS | `fsl_benchmark.py` (simulations) and `fsl_fit_real.py` (in vivo) |

> **Status:** this code was developed for a conference abstract and is still being cleaned up. The interface may change.

## Requirements

- **MATLAB** with the Optimization Toolbox
- **LCModel**
- **OXSA** (for AMARES)
- **FSL-MRS** (Python)

## Basis

The starting basis is provided in `basis_real.mat`; this is the **second basis**.

```matlab
load basis_real.mat
bNew = make_basis_ren2020(basis_real);   % main basis
```

- `make_basis_ren2020.m` rebuilds the NAD⁺, NADH and UDP(G) entries from Ren, Malloy & Sherry, MRM 2020;84:2338. The result is the **main basis**.
- Each component is normalised to its number of ³¹P nuclei, so amplitude ratios are molar ratios.
- `make_amares_pk(bNew)` builds the AMARES prior knowledge for the same basis.

## Data

The in vivo data (7T Siemens Terra.X, frontal cortex, 8×8×8 3D UTE-CSI) are not included in this repository. The simulated spectra are regenerated by `bench_sim_v4.m`.

## Notes on reporting NAD

- In vivo, NADH is often near its detection limit. In the abstract, NADH with a CRLB > 50 % is flagged rather than reported as a value.
- **tNAD** (NAD⁺ + NADH) is the robust outcome, and NAD⁺/tNAD is a bounded alternative to NAD⁺/NADH.
- NAD⁺/NADH is reported only from averaged spectra.
